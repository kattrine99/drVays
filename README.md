# 🏥 Doctor Vays — Medical Landing Page

Современный адаптивный лендинг для медицинской клиники с акцентом на UX, минимализм и доверие пользователя.

---

## 📌 О проекте

Данный проект представляет собой одностраничный сайт (landing page) для медицинской клиники, включающий:

- Главный экран (Hero)
- Услуги с раскрывающимися категориями
- Блок врачей с модальными окнами
- Описание клиники
- Преимущества
- Отзывы пациентов
- Контакты с картой
- Footer

Проект разработан с учетом:
- чистого UI
- адаптивности
- масштабируемости

---

## 🎨 Дизайн

Дизайн выполнен в медицинском стиле:
- Основной цвет: `#E31E24`
- Акцентный: `#C9151B`
- Светлый фон: `#F6F7F9`

Особенности:
- минималистичный интерфейс
- мягкие абстрактные фоны
- иконки в едином стиле
- карточная структура

---

## ⚙️ Технологии

Проект может быть реализован с использованием:

- HTML / CSS / JS
- Tailwind CSS
- React (опционально)
- Swiper.js (слайдеры)
